# Review asset workspace

- `PROMPTS.zh-CN.md`: copy-ready generation prompts and review rules.
- `reference/`: current visual references; do not ship these files as new assets.
- `generated/hat/`: place generated hat candidates here.

Nothing in this directory replaces production assets until it is explicitly approved.
