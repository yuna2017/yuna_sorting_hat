## 观察

- 四部门胜率均衡（24.3%–25.7%），无明显偏差部门；
- 平均分全部落在理论期望 `题数 × (3+1) / 4 = 12.0` 附近，符合四选项主/副推配平；
- 并列率约 9%，其中约 3% 靠决胜题、近 5% 靠主选数拆分，固定顺序兜底最多 1.5% ——
  说明并列大多有"题面内的理由"，不依赖硬编码顺序；
- 领先分差均值≈4（一次主选 + 一次副推），最小 0（并列决胜场景），最大 24（满票型）。

## 改题检查清单

1. 改题后 `npm test && npm run simulate`；
2. 对照本节：胜率偏离 ±3pp 以内可接受，超了就停一下看是哪道题在失衡；
3. 并列率 / 决胜层级分布若大幅跳变，说明决胜题或权重结构被动到了；
4. 把新报告贴回本节作新基线，注明改动。
