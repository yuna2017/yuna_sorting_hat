# 分院帽小游戏
参考项目：[燕山大学人工智能学院简易模拟器](https://www.misakacloud.net/games/ysu-emulator/)

## 项目定位

### 玩法形式
10道左右选择题，每个选项对应不同部门的权重
	（开发部 +3、运维部 +1……）

### 部门映射？

| 学院气质        | 映射部门 | 关键词         |
| ----------- | ---- | ----------- |
| 格兰芬多（勇敢/行动） | 开发部  | 冒险、领导力、现场应变 |
| 拉文克劳（智慧/求知） | 网安部  | 研究、创新、逻辑    |
| 赫奇帕奇（忠诚/耐心） | 运维部  | 协作、细致、服务精神  |
| 斯莱特林（野心/谋略） | 宣传部  | 资源整合、影响力、策略 |
