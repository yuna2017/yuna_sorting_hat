## 信息源优先级

1. `src/data/*.ts`：题目、部门、活动、特质和权重的运行时事实源。
2. `src/lib/*.ts`：计分、抽题、解释、分享和海报的行为事实源。
3. 当前有效 Markdown：解释决策、维护规范和验收流程。
4. `dist/`、截图和导出文件：只作为构建或视觉检查产物，不是信息源。

## 常用维护路径

### 修改题目或权重

阅读 [题库规范](./题库规范.md)，修改 `src/data/questions.ts`，判断是否需要升级 `QUESTION_POOL.version`，然后执行：

```bash
npm test
npm run simulate
npm run build
```

### 修改部门资料或招新入口

修改 `src/data/departments.ts` 或 `src/data/campaign.ts`，确认只使用公共链接，然后执行：

```bash
npm run check:content
node check-depts.mjs
npm run build
```

### 修改页面和交互

更新 [设计文档](./设计文档.md) 中对应的页面结构说明，再修改组件。至少执行：

```bash
npm test
npm run build
node shoot.mjs
```

### 发布

按照 [发布检查清单](./发布检查清单.md) 执行。特别注意 `VITE_PUBLIC_ORIGIN`、`VITE_PUBLIC_PATH`、招新链接和二维码的时效性。
