## 维护约定

**信息源优先级**：代码（.ts / .tsx）> Markdown 文档 > 导出产物（.docx 等）。已输入代码的内容不需二次维护文档。

- **改题目、权重或决胜规则**：更新《题目》→ 更新 `src/data/questions.ts` → 运行 `npm test && npm run simulate`
- **改部门资料或链接**：更新 `src/data/departments.ts` → 核对 contentDraft 状态 → 测试外链有效性
- **改页面流程**：更新《设计文档》《页面细节》→ 更新组件和状态机
- **改分享协议**：更新《设计文档》→ 更新 `src/lib/shareCode.ts` 和兼容测试
- **引入新功能**：先检查《设计文档》边界是否允许；微型故事等扩展列为可选，不阻断招新链路
