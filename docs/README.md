## 同步约定

- 改题目、权重或决胜规则：更新《题目》、题库版本、测试和模拟报告
- 改部门资料或链接：更新部门数据、《部门收集材料》和上线检查
- 改页面流程：更新《设计文档》《页面细节》和根 README
- 改分享协议：更新《设计文档》《TODO》和兼容测试
- 引入新功能：先检查是否符合“不把分部帽扩展为完整人生模拟器”的边界
