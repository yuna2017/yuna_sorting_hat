# 十一、给填写人的说明

请尽量遵循以下原则：

**第一，写事实，不要写套话。**

不要：

> 我们是一个充满活力、团结友爱的优秀团队。

更希望看到：

> 我们负责协会网站和服务器的维护，新成员会从 Git、Linux 和 Docker 开始学习。

**第二，尽量具体。**

不要：

> 会接触很多技术。

更希望：

> 会接触 Python、Flask、Vue、Git 和 Docker。

**第三，不要求“看起来很厉害”。**

这个页面的目的不是让四个部门互相竞争宣传，而是让新生找到：

> **真正适合自己的部门。**

**第四，所有公开信息请确认准确。**

特别是：

- 招新链接
- QQ 群
- 项目链接
- 图片
- 部门介绍
- 技术方向

避免网页上线后出现过期信息或无法访问的链接。
