## 3. 内容写作规则

### 一句话定位

说明这个部门实际负责什么，不写空泛宣传语。

### 部门简介

优先回答：

1. 这个部门负责什么；
2. 真实工作对象是什么；
3. 新成员能够从哪里开始接触。

### 你进来会做什么

写具体的学习、协作、项目或维护任务，保持 2～4 条，避免把工具名堆成技能清单。

### 适合什么样的人

描述行为倾向和工作偏好，不写“能力强”“天赋高”等能力评价。

## 4. 链接和隐私规则

- 只使用协会官网、公开文章、公开仓库、公开报名页和公共招新群；
- 不放个人手机号、私人 QQ / 微信、个人邮箱、内网地址或凭据；
- 链接必须是公开 `http(s)` URL；
- 换届、群失效或活动结束后及时更新 `status`、地址和海报二维码；
- 代表项目缺失时，不写“待补充”到用户界面，优先使用稳定的部门文章分类入口。

