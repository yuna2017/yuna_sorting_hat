## 同步与维护约定

**信息源优先级**：代码（.ts / .tsx）> Markdown 文档 > 导出产物（.docx 等）

| 变更类型 | 文档同步 | 代码同步 | 测试 |
| --- | --- | --- | --- |
| 题目/权重/决胜规则 | 更新《题目》 | 更新 `src/data/questions.ts` | `npm test && npm run simulate` |
| 部门资料/链接 | 更新收集文档 | 更新 `src/data/departments.ts` | 测试外链有效性 |
| 页面流程 | 更新《设计文档》《页面细节》 | 更新组件和状态机 | `npm test` |

| 新功能/扩展 | 检查《设计文档》边界 | 作为可选功能实现 | 完整验收 |
