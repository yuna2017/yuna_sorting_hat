- 判定必须保持零随机，确保分享链接可复现。

- 招新链接只使用协会公共渠道，不提交个人联系方式、内网地址或凭据。
- 修改题库必须提升版本并评估旧分享链接；招新期间避免无计划改题。
- 文档、题库、部门资料和分享协议发生变化时必须同步更新版本说明。
