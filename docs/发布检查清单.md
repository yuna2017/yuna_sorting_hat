# 发布检查清单

> 适用于当前 v3 版本以及后续小版本发布。
>
> 审计日期：2026 年 9 月 4 日

## 1. 发布前：内容与配置

- [ ] 确认活动届次、招新状态和公共招新 URL 正确；
- [ ] 确认四个部门的简介、`doing`、`suitedFor` 和行动入口已核对；
- [ ] 确认 `contentDraft` 全部为 `false`；
- [ ] 确认不包含个人联系方式、内网地址、凭据或测试地址；
- [ ] 确认 `QUESTION_POOL.version` 与 `CAMPAIGN.bankVersion` 一致；
- [ ] 如果改动题目语义、权重、槽位、候选数量或分享协议，已升级版本；
- [ ] 如果只改用户可见文案，已确认没有改变选项语义和答案映射。

## 2. 发布前：开源与版权检查

- [ ] 确认 `LICENSE` 中的版权主体名称准确；
- [ ] 确认 `NOTICE.md` 列出的立绘、logo、二维码和文案授权范围；
- [ ] 确认公开仓库没有个人联系方式、凭据、内网地址或不应公开的素材源文件；
- [ ] 确认第三方依赖按照各自许可证使用；
- [ ] 确认 `CONTRIBUTING.md` 和 `SECURITY.md` 中的仓库流程适用于当前维护方式。

## 3. 发布前：自动化检查

在仓库根目录执行：

```bash
npm ci
npm test
npm run check:content
npm run simulate
npm run build
```

要求：

- 所有单元测试通过；
- 内容校验通过；
- 四部门都可胜出，平均分和并列率没有异常；
- 生产构建通过；
- `dist/` 生成正常。

## 4. 发布前：浏览器验收

需要 Microsoft Edge 和仓库开发依赖中的 Playwright：

```bash
node shoot.mjs
node check-depts.mjs
```

重点确认：

- 封面、开场、答题、仪式和结果流程可完成；
- 仪式可以跳过，减少动态效果不会长时间等待；
- 结果页只有浏览器主滚动条；
- 320 / 360 / 390 / 412px 没有横向溢出；
- 844 × 390 横屏没有横向溢出；
- 结果解释、部门介绍、行动入口和分享区齐全；
- 图片模式默认可见，海报生成尺寸为 1080 × 1920；
- 网页模式可以复制可复现链接；
- 四个部门的详情页和立绘可以加载；
- 页面没有 console error。

## 5. 发布环境变量

### 当前正式域名

```text
VITE_BASE=/
VITE_PUBLIC_PATH=/
VITE_PUBLIC_ORIGIN=https://ysh.yuna.team
```

### GitHub Pages 子路径或其他自定义域名

```text
VITE_BASE=<实际资源根路径>
VITE_PUBLIC_PATH=<实际二维码路径>
VITE_PUBLIC_ORIGIN=https://实际公开域名
```

`VITE_PUBLIC_ORIGIN` 必须是用户真正可以访问的公开域名，不要填 localhost、内网 IP、预览域名或带路径的地址。
