# 注意事项

## 移动端

- 已完成部分移动端尺寸验证，后续仍需覆盖 Android Chrome、iOS Safari 和微信内置浏览器。
- 检查 320 / 360 / 390 / 412px 下无横向溢出。
- 检查说明卡、底部操作按钮和长分享链接在窄屏下的可用性。
- 地址栏高度差异可能影响 `dvh`，必须进行真机验收。

## 内容与外链

- 部门正式资料由社团确认后再写入项目。
- 部门介绍优先链接到社团官网。
- 招新入口只使用公共 URL，不放个人联系方式、内网地址或凭据。

## 题库与分享

- 修改题目后运行 `npm test`。
- 题库变化可能改变旧分享链接的结果，招新期间不要无计划改题。
